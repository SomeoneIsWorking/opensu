# openSU updater, and a system updater for the openSU distro

Status: planned.

The player (2026-11-27, Ally): "Oh and record that we need an updater for openSU and also a system
updater if we make the openSU distro".

- openSU updates itself: it finds a newer release of its own package (AppImage, the platform
  installers, the APK) and installs it, the running copy replaced at the next start.
- The openSU distro (`docs/ideas.md`, "An openSU distro"), if it is made, gets a system updater in
  openSU for the OS image itself.
